# FRONTEND DEVELOPMENT TUTORIALS

Welcome to the FrontEnd Development Tutorials repository!

This project is a structured, step-by-step learning resource containing core web development concepts, practical code examples, and practice exercises.

# REPOSITORY STRUCTURE

1. HTML

---

Folder: 1_HTML/

Topics covered:

- Semantic HTML5 elements
- Forms
- Media tags
- Basic web page structure
- HTML fundamentals

2. CSS

---

Folder: 2_CSS/

Topics covered:

- CSS fundamentals
- Box Model
- Flexbox
- CSS Grid
- Animations
- Responsive Design
- Styling and Layout techniques

3. JAVASCRIPT

---

Folder: 3_JAVASCRIPT/

Topics covered:

- JavaScript fundamentals
- Variables and Data Types
- Functions
- DOM Manipulation
- ES6+ Features
- Array Methods
- Promises
- Async/Await
- API Integration

4. BOOTSTRAP

---

Folder: 4_Bootstrap/

Topics covered:

- Bootstrap fundamentals
- Bootstrap Grid System
- Responsive Layouts
- Bootstrap Utilities
- UI Components
- Responsive Web Design

# TECH STACK

HTML5

- Used for webpage structure and markup.

CSS3

- Used for styling, layouts, animations, and responsive design.

JavaScript (ES6+)

- Used for client-side logic and dynamic features.

Bootstrap

- Used for creating responsive layouts and UI components.

# GETTING STARTED

1. Clone the repository:

git clone https://github.com/Anas-syed89/FrontEnd-Development-Tutorials.git

2. Navigate to the project directory:

cd FrontEnd-Development-Tutorials

3. Run the files:

- Open HTML files directly in your browser.
- Use VS Code with Live Server for HTML/CSS projects.
- Run JavaScript files using Node.js when required.
